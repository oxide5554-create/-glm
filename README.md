# RUST — однопользовательская сборка

Сборка игры **Rust** (clone) на JavaScript + Three.js без папки `scr/3d/` (оружие и модели игрока) и без мультиплеера.

**Оружие и модели игрока будут добавлены с нуля позже.** Сейчас игра содержит весь мир и UI:
- локации (заправки, склады/амбары, машины, багги, блокпосты),
- природу (деревья, кусты, папоротники, цветы, трава),
- UI (хотбар, инвентарь, крафт-меню — пустое, меню строительства),
- настройки графики,
- звуки,
- 🐻 **чёрных медведей** (модель из Call of the Wild, ИИ, лут).

---

## Запуск

### Способ 1: простой локальный сервер (рекомендуется)

```bash
cd rust
node server.js
```

Открой в браузере: **http://localhost:8080**

### Способ 2: любой статический HTTP-сервер

```bash
cd rust
python3 -m http.server 8080
# или
npx serve .
```

> **Важно:** играть через `file://` не выйдет — браузеры блокируют ES-модули из локальных файлов. Нужен любой HTTP-сервер.

### Зависимости

**Никаких.** Сервер использует только встроенный модуль Node.js (`http`, `fs`). Three.js подгружается из CDN через `<script type="importmap">`.

## 🐻 Медведи

В лесу бродят **чёрные медведи** (6 шт., респавн автоматически). Модель — рип из
*theHunter: Call of the Wild* (скелет 109 костей, 15 анимаций, встроенная текстура).

**Поведение (ИИ):**
- **Покой** — стоит, принюхивается, ест, иногда встаёт на задние лапы.
- **Блуждание** — ходит вокруг точки спавна.
- **Тревога** — заметил игрока: рычит, встаёт на задние лапы.
- **Погоня** — атакует: галопом/бегом догоняет игрока.
- **Атака** — удар лапой (~27 HP за удар).
- **Смерть** — падает на бок, труп можно обобрать (медвежатина 🍖 +4…8).

**Механики:**
- ⚔️ Урон по медведю: топор/камень — 45, АК-47 — 38 за попадание (HP 220).
- 👀 Обнаружение: ~22 м. **Присед (C) снижает радиус в ~2 раза, бег — увеличивает.**
- 🚗 В багги медведь не может ударить игрока.
- 🔊 5 звуков (рычание, рёв, лай, боль, смерть) — сгенерированы процедурно, громкость зависит от дистанции.
- ⚙️ Оптимизация: медведи дальше 180 м «заморожены», дальше 190 м скрыты (distance culling).
- 🖥️ Дебаг: `window.__bearManager` в консоли браузера.

  - Скелет 109 костей + 15 анимаций (idle/walk/canter/run/attack/hit/death/stand/…)
  - Встроенная текстура, обрезано с 26 МБ (81 анимация → 15 нужных)
  - Загружается в `scr/world/bear.js` (класс `Bear` + `BearManager`)
  - Лицом в +Z, размер реальный (~2.3 м в длину), масштаб слегка вариативен
- **`player.glb`** (19.7 МБ) — модель игрока в трусах (как в начале Rust).
  - Загружается через `FirstPersonPlayer` (см. `scr/3d/firstPersonPlayer.js`)
  - Привязывается к камере от 1-го лица, голова обрезается clipping plane
  - Масштабируется под 1.75 м роста
  - Используется как "тело игрока" в 1-м лице + модель 3-го лица (в превью)
- **`stone_axe.glb`** (27.6 МБ) — каменный топор (кремень + ремни + палка).
  - Загружается через `createStoneAxe` (см. `scr/3d/stoneAxe.js`)

## Как добавить новое оружие (позже)

1. Создай файл `scr/3d/myWeapon.js` с экспортом `createMyWeapon(camera, scene)`.
   Возвращай объект с методами:
   ```js
   { group, setVisible(v), update(dt, opts), fire(target), dispose }
   ```
2. Добавь иконку в `scr/ui/icons/myWeapon.png`.
3. В `scr/ui/hotbar.js` добавь запись в `ITEMS`:
   ```js
   myWeapon: { id: 'myWeapon', name: 'Моё оружие', icon: './scr/ui/icons/myWeapon.png', stackable: false }
   ```
4. В `scr/ui/craftmenu.js` добавь рецепт в `RECIPES`:
   ```js
   { id: "myWeapon", cat: "tools", icon: "./scr/ui/icons/myWeapon.png", name: "Моё оружие",
     cost: { wood: 50, scrap: 30 }, time: 2, count: 1, desc: "Описание" }
   ```
5. В `main.js`:
   - добавь импорт `import { createMyWeapon } from './scr/3d/myWeapon.js';`
   - создай экземпляр: `const myWeapon = createMyWeapon(camera, scene);`
   - в `hideAllWeapons()` добавь `myWeapon.setVisible(false);`
   - в `checkActiveWeapon()` добавь ветку для `item.id === 'myWeapon'`
   - в обработчике `mousedown` добавь логику выстрела
   - в `animate()` вызови `myWeapon.update(delta, { speed, sprint, onGround });`

Готово — оружие работает в игре.

## Технические детали

- **Three.js v0.160.0** подгружается из CDN через `importmap`.
- **Пост-обработка**: Bloom + Color Grading + FXAA + volumetric sky shader.
- **Адаптивное качество**: 5 уровней, авто-переключение по FPS.
- **Distance culling**: дальние объекты скрываются для оптимизации.
